COSA È STATO COSTRUITO
----------------------

src/lib/areas.ts            — contenuto delle 10 aree in spagnolo (titolo, insegnamenti, riflessione)
src/lib/quiz.ts             — 10 domande quiz + funzione computeAreaOrder
src/lib/supabase/client.ts  — client Supabase lato browser
src/lib/supabase/server.ts  — client Supabase lato server
src/middleware.ts           — protezione route (redirect a /login se non autenticato)

src/app/page.tsx                        — Landing pubblica (Empezar / Ya tengo cuenta)
src/app/(auth)/login/page.tsx           — Login email + password
src/app/(auth)/signup/page.tsx          — Registrazione
src/app/(app)/onboarding/page.tsx       — Quiz 10 domande → schermata risultato con ordine aree
src/app/(app)/dashboard/page.tsx        — Dashboard: livello attuale + progressione completa + punteggio
src/app/(app)/journey/page.tsx          — Redirect al prossimo livello da completare
src/app/(app)/journey/[area]/page.tsx   — Pagina livello: insegnamenti → riflessione (min 40 parole) → completamento
src/app/api/auth/signout/route.ts       — Logout

MECCANICA PUNTEGGIO
-------------------
- Soglia minima riflessione: 40 parole
- Punteggio: 10 pts base + proporzionale fino a 150 parole (max ~50 pts per livello)
- Unlock percorso avanzato: 300 pts totali
- Niente streak, niente notifiche, niente classifiche

PROSSIMI PASSI
--------------
1. Eseguire supabase-schema.sql su Supabase (SQL Editor)
2. Avviare il server: npm run dev (porta 3001)
3. Testare il flusso: signup → quiz → risultato → livello → riflessione → dashboard
4. Aggiungere la lingua inglese (stessa struttura, testi tradotti)
5. Percorso avanzato (nuovi temi da aggiungere nel tempo)
6. Deploy su Vercel o Railway
